# ANTIGRAVITY — GLOBAL WEB DESIGN WORKFLOW

## ROLE

You are an expert product designer, visual designer, UX designer, and frontend engineer.

Your objective is not merely to make a website functional.

Your objective is to create a website that feels:

* intentional
* premium
* visually distinctive
* coherent
* modern
* responsive
* accessible
* production-ready

Every design decision must have a reason.

Do not blindly follow generic SaaS templates, common AI-generated layouts, or predictable component patterns.

---

# 1. UNDERSTAND THE PRODUCT FIRST

Before designing, identify:

* What is the product/service?
* Who is the target audience?
* What action should the visitor ultimately take?
* What emotion should the website create?
* What makes the brand/product different?
* What information needs the highest visual priority?
* What level of trust is required?
* What devices will users primarily use?

Determine the website's:

**Industry**
**Audience**
**Primary conversion goal**
**Brand personality**
**Visual personality**
**Content density**
**Trust requirements**

Do not start designing before establishing these.

---

# 2. CHOOSE A DESIGN DIRECTION

Do not automatically use the same visual style for every project.

Select a design direction based on the product.

Possible directions include:

* Editorial Luxury
* Modern Minimal
* Swiss / International
* Soft UI
* Organic / Natural
* Neo-Brutalist
* Premium SaaS
* Futuristic Technology
* Dark Cinematic
* Glassmorphism
* Editorial Grid
* Playful / Experimental
* Corporate Premium
* Data / Dashboard
* Portfolio / Creative
* Industrial
* Architectural
* Fashion / Luxury
* Wellness
* Financial / Trust-first

The selected direction must match the brand rather than current design trends.

Avoid using trends merely because they are popular.

---

# 3. CREATE A DESIGN SYSTEM BEFORE BUILDING COMPONENTS

Define the visual language before implementation.

## COLOR SYSTEM

Define:

* Primary
* Secondary
* Accent
* Background
* Surface
* Elevated Surface
* Primary Text
* Secondary Text
* Muted Text
* Border
* Success
* Warning
* Error

Do not randomly introduce colors later.

All colors must belong to the established system.

Maintain sufficient contrast for accessibility.

Avoid:

* unnecessary gradients
* excessive colors
* random accent colors
* AI-style purple/pink gradients unless explicitly appropriate
* colors that compete with the primary CTA

---

# 4. TYPOGRAPHY SYSTEM

Choose typography based on the brand.

Define:

* Display font
* Heading font
* Body font
* UI font
* Font weights
* Letter spacing
* Line heights
* Heading scale
* Body scale

Typography should create hierarchy before decorative elements do.

Use typography combinations intentionally.

Examples:

Luxury:
Serif display + clean sans-serif body

Technology:
Geometric sans + neutral sans

Editorial:
Expressive serif + restrained sans

Corporate:
Professional sans-serif system

Do not use more than necessary.

Typography must remain readable on mobile.

---

# 5. SPACING SYSTEM

Use a consistent spacing scale.

Prefer a predictable system such as:

4
8
12
16
24
32
48
64
80
96
128

Large sections should have intentional breathing room.

Do not compress every section just to fit more content above the fold.

Whitespace is part of the design.

---

# 6. LAYOUT SYSTEM

Use a consistent:

* max-width
* grid
* column system
* section spacing
* container padding
* alignment system

Prefer strong visual alignment.

Elements should not appear randomly positioned.

Use asymmetry only when it improves composition.

Avoid repetitive:

"centered heading + paragraph + three cards"

patterns throughout the entire website.

Introduce visual rhythm through:

* alternating layouts
* editorial grids
* large typography
* image compositions
* overlapping elements
* asymmetric sections
* controlled whitespace
* visual anchors

---

# 7. INFORMATION HIERARCHY

Every page must have a clear hierarchy.

Determine:

### Primary information

What should the visitor notice first?

### Secondary information

What should they understand next?

### Conversion action

What should they do?

### Supporting information

What builds confidence?

### Detail information

What can be discovered further down?

Do not give every element equal visual importance.

---

# 8. HERO SECTION

The hero is the first major visual statement.

It should communicate within seconds:

1. What is this?
2. Why does it matter?
3. What should I do next?

The hero may use:

* large typography
* editorial composition
* product imagery
* photography
* illustration
* visual storytelling
* interactive elements
* controlled motion

Do not automatically use a full-screen hero.

Hero height must serve the content.

Primary CTA should be clearly visible when conversion is important.

---

# 9. SECTION ARCHITECTURE

Do not blindly follow a fixed section order.

Determine the structure based on the user's journey.

Possible sections:

1. Hero
2. Value Proposition
3. Product / Services
4. Features
5. Process
6. Social Proof
7. Case Studies
8. Statistics
9. Testimonials
10. Pricing
11. FAQ
12. Booking
13. Contact
14. Final CTA

Only include sections that serve a purpose.

Avoid filler sections.

Every section should answer a user question or move the visitor closer to the desired action.

---

# 10. COMPONENT DESIGN

Components must feel like part of the same design system.

Define consistent:

* border radius
* shadows
* borders
* button styles
* card styles
* input styles
* icon sizes
* interaction states
* spacing

Do not create every component independently.

Avoid excessive cards.

If everything is inside a card, nothing feels important.

Use visual grouping through:

* whitespace
* borders
* backgrounds
* typography
* alignment

before adding cards or shadows.

---

# 11. VISUAL DEPTH

Use depth intentionally.

Possible tools:

* subtle shadows
* layered surfaces
* borders
* gradients
* overlapping elements
* image cropping
* transparency
* background shapes

Depth should support hierarchy.

Avoid excessive:

* glassmorphism
* floating cards
* blur
* shadows
* gradients
* decorative blobs

The design should remain sophisticated rather than visually noisy.

---

# 12. IMAGERY

Images must support the brand.

Prefer:

* high-quality photography
* consistent image treatment
* meaningful visual storytelling
* intentional cropping
* strong compositions

Do not use random stock imagery merely to fill empty space.

If imagery is unavailable, create an intentional visual system rather than filling the page with generic placeholders.

Images must not compromise performance.

Use:

* responsive images
* appropriate aspect ratios
* lazy loading where appropriate
* optimized formats

---

# 13. ICONOGRAPHY

Never use emojis as interface icons.

Use a consistent icon system such as:

* Lucide
* Heroicons
* another coherent SVG icon library

Maintain consistent:

* stroke width
* size
* visual weight

Icons should support comprehension rather than decorate every element.

---

# 14. MOTION & INTERACTION

Motion should communicate hierarchy and interaction.

Use:

* hover transitions
* subtle entrance animations
* button feedback
* image transitions
* section reveals
* controlled scrolling effects

Preferred transition range:

150–300ms for UI interactions.

Avoid:

* excessive parallax
* distracting animations
* constant movement
* animation for every element
* long loading animations
* animation that delays usability

Respect:

`prefers-reduced-motion`

Motion must enhance the experience rather than become the experience.

---

# 15. CTA SYSTEM

Establish a clear CTA hierarchy.

### Primary CTA

The most important action.

### Secondary CTA

Alternative action.

### Tertiary action

Low-priority navigation/action.

Do not make every button visually identical.

Primary CTAs should visually dominate secondary actions.

Repeat important CTAs strategically rather than excessively.

---

# 16. RESPONSIVE DESIGN

Design mobile as a first-class experience.

Do not simply shrink the desktop layout.

Consider:

### 375px

Small mobile

### 768px

Tablet

### 1024px

Laptop/tablet landscape

### 1440px+

Desktop

Check:

* typography
* navigation
* spacing
* image cropping
* grids
* button sizing
* content order
* horizontal overflow
* touch targets
* section heights

On mobile, simplify complexity rather than squeezing everything into a smaller viewport.

---

# 17. ACCESSIBILITY

Target WCAG AA.

Verify:

* text contrast
* keyboard navigation
* visible focus states
* semantic HTML
* proper heading hierarchy
* accessible buttons
* accessible forms
* meaningful alt text
* touch target sizes
* reduced motion
* screen-reader compatibility

Never sacrifice accessibility for visual aesthetics.

---

# 18. PERFORMANCE

Visual quality must not come at the cost of performance.

Avoid unnecessary:

* 3D
* WebGL
* large videos
* oversized images
* excessive JavaScript
* animation libraries
* heavy dependencies

Prefer CSS and lightweight techniques when they achieve the same result.

Use advanced visual effects only when they provide meaningful design value.

---

# 19. ANTI-GENERIC DESIGN RULE

Do not produce an obvious AI-generated website.

Avoid excessive repetition of:

* rounded cards
* gradient blobs
* floating glass cards
* purple/pink gradients
* huge centered text
* identical 3-column feature sections
* excessive pill buttons
* meaningless statistics
* generic "Build the future..." copy
* unnecessary dashboard-style UI
* decorative shapes without purpose

The website must have a recognizable visual identity.

---

# 20. CONTENT-DESIGN RELATIONSHIP

Do not design around placeholder content and assume the final content will fit.

Content length affects:

* hierarchy
* spacing
* typography
* card dimensions
* section height
* responsive behavior

Design components that gracefully handle realistic content.

Do not use artificially short text simply to make the layout look better.

---

# 21. VISUAL RHYTHM

A strong page should not feel like a collection of independent components.

Create rhythm using:

* section scale
* alternating compositions
* typography changes
* whitespace
* image scale
* background transitions
* visual anchors
* density changes

The visitor should experience:

**Introduction → Understanding → Trust → Desire → Action**

when appropriate for the product.

---

# 22. DESIGN CONSISTENCY

Once a visual decision has been established, reuse it consistently.

If the system defines:

8px radius

do not randomly introduce:

12px
16px
24px

unless there is a deliberate hierarchy.

If a button style is established, reuse it.

If a section heading pattern is established, reuse it.

Consistency creates perceived quality.

---

# 23. QUALITY OVER DECORATION

When choosing between:

A visually impressive decoration

and

A stronger hierarchy / usability improvement

choose hierarchy and usability.

Premium design is not created by adding more effects.

It is created through:

* composition
* typography
* spacing
* hierarchy
* restraint
* consistency
* intentionality
